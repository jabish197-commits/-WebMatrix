# WebMatrix deployment

Recommended production layout:

- Supabase: PostgreSQL database and uploaded images
- Render: Express API in `server/`
- Vercel: Vite/React client in `client/`

## 1. Prepare Supabase

Run these files in the Supabase SQL Editor in this order:

1. `server/supabase/schema.sql`
2. `server/supabase/razorpay-payment.sql`
3. `server/supabase/upi-settings.sql`

Confirm the `webmatrix-assets` Storage bucket exists and review the Supabase Security Advisor before launch.

## 2. Push WebMatrix to GitHub

Create a private GitHub repository and push the `WebMatrix` directory. Never commit `server/.env`, API secrets, service-role keys, or Razorpay secrets.

## 3. Deploy the API to Render

In Render choose **New → Blueprint**, connect the GitHub repository, and select `render.yaml`.

Provide these secret values when Render asks:

```env
CLIENT_URL=https://your-vercel-project.vercel.app
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-real-service-role-key
```

`JWT_SECRET` is generated by Render. Add the following later only when Razorpay is ready:

```env
RAZORPAY_KEY_ID=rzp_live_or_test_key
RAZORPAY_KEY_SECRET=your-secret
```

The Render health check is `/api/health`. After deployment, copy the API URL, for example:

```text
https://webmatrix-api.onrender.com
```

## 4. Deploy the client to Vercel

Import the same GitHub repository in Vercel and use:

```text
Framework preset: Vite
Root directory: client
Build command: npm run build
Output directory: dist
```

Add this Vercel environment variable for Production and Preview:

```env
VITE_API_URL=https://webmatrix-api.onrender.com/api
```

Deploy and copy the final Vercel URL.

## 5. Final CORS update

Return to the Render service and set `CLIENT_URL` to the exact final Vercel origin, without a trailing slash:

```env
CLIENT_URL=https://your-final-domain.vercel.app
```

Render will redeploy. Confirm both URLs work:

```text
https://webmatrix-api.onrender.com/api/health
https://your-final-domain.vercel.app
```

## 6. Seed production data (once)

From a trusted local computer with `server/.env` pointing to the production Supabase project, run:

```powershell
npm.cmd run seed
npm.cmd run seed:commerce
```

Do not run seeds automatically during every production deployment.

## 7. Launch checks

- Register and log in as a customer.
- Log in as Admin and Super Admin in separate browser tabs.
- Test image uploads.
- Place a Cash on Delivery test order.
- Test UPI using Razorpay Test Mode before Live Mode.
- Confirm payment records and order status in the dashboard.
- Replace Razorpay test keys with live keys only after KYC and end-to-end testing.
