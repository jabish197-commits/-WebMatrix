# API

- `POST /api/auth/register` — register a Customer.
- `POST /api/auth/login` — authenticate any active user.
- `GET /api/auth/me` — return the authenticated user.
- `GET /api/settings/public` — public branding and content.
- `PATCH /api/settings` — Super Admin only.
- `GET /api/users` — permitted Admin or Super Admin.
- `POST /api/admins` — Super Admin only.
- `GET /api/dashboard` — authenticated dashboard information.
